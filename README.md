🐍 Python Assignment 3 – Loops and Functions
📘 Overview
This project demonstrates fundamental Python concepts — while loops, for loops, and functions — through three beginner-friendly programs:

Number Guessing Game

Multiplication Table Generator

BMI Calculator

🎯 Learning Objectives
Understand and apply loop control statements (break, continue, else).

Use for and while loops for iteration and condition-based repetition.

Define and call functions to structure reusable code.

Handle user input and display formatted output.

🧩 Program Details
1️⃣ Number Guessing Game
Generates a random number between 1 and 10.

User guesses within limited attempts.

Demonstrates while, break, and continue.

2️⃣ Multiplication Table Generator
Uses a for loop and range() to print a table (1–10).

Reinforces iteration and formatted output.

3️⃣ BMI Calculator
Defines a function calculate_bmi(weight, height) to compute BMI.

Shows how to use parameters, return values, and formatted printing.

🧠 Sample Concepts
Concept	Example
While Loop	while attempts > 0:
For Loop	for i in range(1, 11):
Function	def calculate_bmi(weight, height):
Control Statements	break, continue, else
